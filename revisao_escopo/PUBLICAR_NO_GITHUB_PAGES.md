# Publicar no GitHub Pages

1. Extraia o ZIP do site no computador.
2. Crie ou abra seu repositório no GitHub.
3. Envie index.html, styles.css, script.js, LICENCA.txt e a pasta downloads para a raiz. Preserve a pasta downloads com o ZIP do plugin dentro. O arquivo .nojekyll pode ser incluído. Não envie apenas o ZIP do site: o GitHub Pages precisa dos arquivos extraídos.
4. Em Settings > Pages, escolha Deploy from a branch. Selecione a branch que recebeu os arquivos (geralmente main) e a pasta / (root). Salve. Se a interface diferir, consulte https://docs.github.com/pages .
5. Aguarde a publicação e abra o endereço informado pelo GitHub.
6. Confira o download do plugin e os botões de copiar. Na seção Como citar, a URL do GitHub Pages será detectada automaticamente; você também pode editá-la.

## Estrutura
index.html — página
styles.css — visual responsivo
script.js — copiar textos e montar referências; sem envio de dados
downloads/pesquisa-primeira-string-v1.0.0.zip — plugin para o visitante baixar
LICENCA.txt — autorização não comercial

## Atualizar o plugin
Substitua o ZIP em downloads pela nova versão exportada e atualize nome do arquivo, links e versão em index.html. O site não altera automaticamente o plugin original nem publica no diretório da OpenAI.
