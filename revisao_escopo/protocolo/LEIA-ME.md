# Site do plugin protocolo PRISMA-ScR — GitHub Pages

## Arquivos do pacote
- index.html: página principal com guia de instalação e uso.
- styles.css: estilos responsivos.
- downloads/protocolo-prisma-scr-v1.0.7.zip: pacote instalável do plugin.
- .nojekyll: permite servir os arquivos estáticos sem processamento Jekyll.

## Publicar no GitHub Pages
1. Extraia o ZIP DO SITE em seu computador. Não extraia o ZIP DO PLUGIN dentro da pasta downloads.
2. No repositório do site, crie uma pasta, por exemplo protocolo_prisma_scr, ou use a raiz/pasta docs da origem configurada no Pages.
3. Envie index.html, styles.css, .nojekyll e a pasta downloads mantendo a estrutura. Evite uma pasta extra entre a pasta desejada e index.html.
4. Se o Pages ainda não estiver configurado, acesse Settings > Pages e configure a publicação a partir da branch e da pasta que contêm os arquivos (raiz ou docs, conforme seu repositório).
5. Aguarde a publicação. Abra a URL fornecida pelo GitHub Pages e acrescente o caminho da subpasta, se utilizou uma.
6. Teste o botão de download. Ele deve baixar downloads/protocolo-prisma-scr-v1.0.7.zip.

Se já existe um site, mantenha a configuração de publicação e envie esta página para uma subpasta da origem publicada. Este pacote não altera ou publica seu repositório automaticamente.

## Etapa inicial obrigatória
Antes de criar o protocolo, execute o plugin Pesquisa | Do Tema à String pelo guia:
https://anapaulacostacurta-ifpr.github.io/anapaulacostacurta-ifpr/revisao_escopo/
Esse guia apresenta as instruções de instalação e uso. Ao concluir a etapa inicial, salve o documento de tema e string preliminar e anexe-o na conversa do protocolo. As instruções detalhadas de instalação foram retiradas desta página para evitar repetição. O botão de download do pacote do plugin protocolo PRISMA-ScR foi mantido.

## Funcionamento
Site em HTML e CSS, sem JavaScript, dependências externas ou formulário de upload. Os anexos são enviados na conversa com o plugin. Links relativos garantem o download em subpastas do GitHub Pages. O botão de download não direciona ao plugin privado da autora. O pacote do plugin foi obtido da versão 1.0.7 existente; as instruções metodológicas não foram alteradas.
