# Atividade Sub-redes com login Google

HTML, CSS e JavaScript sem compilação. Vídeo MP4 sem áudio incluído. Diagnóstico > charada > vídeo/questionário > conclusão.

## GitHub Pages
Extraia o ZIP e envie os arquivos à raiz do repositório. index.html, style.css, app.js, firebase.js e video.mp4 devem ficar lado a lado. Settings > Pages > Deploy from a branch > main > / (root) > Save. Não há pacote npm.

Leia FIREBASE.md e ative Google, autorize o domínio e publique as novas regras. Teste o login real e os envios antes da aula.

A sintaxe JavaScript e isolamento dos rascunhos por conta foram testados com simulação local. O login OAuth e as gravações reais dependem da configuração Firebase e não foram testados nesta entrega. A publicação em Sites preserva o acesso atual; para a turma pode-se utilizar GitHub Pages.

Mudanças de domínio não migram progresso local. Dados anônimos anteriores não são migrados para Google. Rascunhos pertencem à conta e domínio. A mesma conta no mesmo navegador retoma o andamento. Contas diferentes não exibem os rascunhos umas das outras na interface, mas arquivos locais do perfil não são armazenamento criptografado. Saia ao terminar em computadores compartilhados.

Não envie respostas JSON ou credenciais privadas ao GitHub. O download de respostas permanece como cópia de segurança. Confirme a entrega no Firestore.
